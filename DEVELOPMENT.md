# TAPE LAB — Development

## Current milestone

TAPE v0.1: audio foundation for Swift Playgrounds on iPad.

Priority: real audio import, playback, pause, seeking, and waveform display. Reverse touch transport, DRUM and FM are later milestones.

## Verification policy

Code committed to this repository is not assumed to be built or tested on iPad. Device validation will be recorded explicitly after user confirmation.

## Branch policy

Keep `main` unchanged until the feature is validated; develop incremental iterations on feature branches.
